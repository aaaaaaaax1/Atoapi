# Atoapi v1.5.14

## 路由修复

- 同一上游可同时保存多个模型映射，即使多个请求模型名指向同一实际模型；新增映射和删除映射前会先同步当前输入，避免重绘覆盖刚填写的映射。
- 会话管理支持自定义显示名称，双击名称或点击铅笔即可修改；会话 ID 与分组绑定保持不变。
- 缓存统计页恢复纵向滚动，概览、趋势和请求记录可正常浏览。

## 上游与 Key 容错

- 备用上游严格按分组中的排序使用，不再在每条消息之间轮询；当前线路正常时持续沿用，只有切换条件满足后才按顺序推进。
- 同一会话、同一上游连续遇到两次 503 后才切换备用上游，第一次 503 保留原线路作为一次容错。
- Key 池在已有可用成功记录时保持 Key 黏性，避免上下文压缩或后续轮次无故换 Key；新 Key 池仍严格按用户配置顺序开始。
- 修复编辑已有 Key 时替换密钥可能未保存的问题；新密钥会立即覆盖旧值并重置该 Key 的旧健康记录。

## 验证

- Rust 单元测试：1121 通过，0 失败，12 个手动基准忽略。
- 前端 TypeScript 与 Vite 生产构建通过。
- 缓存统计页已用实际浏览器验证可滚动到底部。
