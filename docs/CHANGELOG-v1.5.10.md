# Atoapi v1.5.10

## Codex 分组界面

- 上游列表隐藏 Codex 专用的“使用/当前”快捷绑定按钮，避免与分组路由重复。
- 分组新建改为单按钮弹窗，提供名称输入、取消和保存。
- 分组名称支持双击修改；默认分组名称保持固定。
- 分组编辑、排序、移除与删除先暂存，右下角统一显示“保存配置”和“删除分组”；保存失败时保留未保存内容。
- 分组上游支持拖动排序，并显示线路、可用 Key、模型数、最近连通状态；可直接探测余额和测试连通性。
- 分组卡片、操作区和弹窗调整为更清晰的分层配色与紧凑布局。

## 保持兼容

- 沿用 v1.5.9 的分组路由、会话绑定、上下文设置和注入行为；没有变更路由后端数据格式。
- 不修改其他 Agent 的上游绑定操作。
