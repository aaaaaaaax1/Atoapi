# Atoapi v1.5.16

## Codex 分组与会话路由

- 修复会话切换分组后，正在进行的旧请求完成时可能把旧线路重新写回的问题。当前回复不切换，下一条请求按新分组生效。
- 分组内关闭某上游的“备选”开关后，该上游完全退出此分组的选路，包括首位、已有会话固定线路、续接线路和故障切换候选。所有上游都关闭时明确报告该分组没有可用线路。
- 每个分组的备选设置仍独立保存；同一上游在其他分组的设置不受影响。

## 界面

- 请求记录的分组筛选改为应用内深色下拉菜单，避免 Windows 原生菜单出现浅色背景与浅色文字难以辨认的问题。
- 会话切组保存提示明确说明：当前回复继续完成，新分组从下一次请求生效。

## 验证

- Codex Rust 回归测试、分组筛选 UI 测试、上下文设置桥接测试及上游显示测试通过。
- TypeScript/Vite 生产构建通过。
