# Atoapi v1.5.15

## 模型映射保存修复

- 映射唯一键改为“实际模型 ID + 请求模型名”。同一实际模型可保留多个请求模型映射，例如 `gpt-5.6-luna` 和 `gpt-6.1-sol` 同时映射到一个上游模型。
- 编辑和回填既有模型配置时也按完整映射键查找，避免共享实际模型的映射互相覆盖上下文或推理设置。
- 增加回归测试，覆盖多个请求模型指向同一实际模型、相同映射去重和映射回填身份。

## Codex 分组与会话路由修复

- 备选开关现在保存在各自分组内。同一上游加入多个分组时，每组可独立决定是否参与备选；旧版全局排除设置会迁移到包含该上游的分组。
- 修复托管会话切组后的旧线路绑定判定，确保后续请求按新分组顺序选择上游。跨上游的续接 ID 仍须经本地历史证明并重建，不会将旧上游 ID 直接发送给新上游。
- 优化并发会话的线路观察：线路未变且会话记录刚刷新时，通过共享读锁直接跳过，不再为普通成功请求申请全局配置写锁、复制完整配置；确有线路或历史时间更新时仍在写锁内复查后保存。
- 请求记录显示本次实际使用的分组名和会话备注，并可按成功使用过的分组筛选。
- 增加分组独立开关、旧设置迁移、线路切换和续接 ID 隔离回归测试。

## 验证

- Rust 路由、迁移、续接线路及未变化线路观察回归测试通过。
- 前端映射与 Codex 分组 UI 回归测试、TypeScript/Vite 生产构建通过。
