# Atoapi v1.5.9

## Codex 分组与会话路由

- 上游页增加固定“默认分组”和可自定义线路分组；分组内可调整上游顺序、添加或移除上游。移除仅解除分组引用，不删除上游本身。
- 新会话使用默认分组；已纳入管理的会话可以单独选择分组。上游顺序按组生效，Key 不可用时会跳过该线路。
- 最近会话历史最多保留 10 条；可纳入管理、移出管理、删除记录或清空历史。已管理会话与线路续接绑定独立保存。
- 旧配置首次升级时，将当时 Codex 已绑定线路迁移至默认分组；用户之后明确清空的分组不会在启动时被重新填充。
- 已有会话的 `previous_response_id` 继续使用原线路。用户改组后，仅在本地存在可验证的完整历史时才会去除旧响应 ID 并在目标线路重建上下文；缺少可重建历史或原线路不可用时明确报冲突，不把续接 ID 发给其他上游。
- 会话线路只在上游成功响应后更新，失败请求不会提前覆盖原线路。每个入站请求仍只发送一次；网络超时或断流不会隐式重试。

## 其他

- 保留原有 Codex 上下文窗口与自动压缩阈值设置。
- 保留 v1.5.8 的有界工具传递诊断默认状态和数据范围；不记录完整聊天或工具正文。
- Codex 设置页改为固定左侧导航和独立右侧内容滚动；切换上游、分组管理、会话管理或上下文设置时只显示当前页面，不再把页面连续堆叠在下方。
